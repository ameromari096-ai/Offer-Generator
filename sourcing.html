Chat with the PureHealth Sourcing Agent

This is the live PureHealth Sourcing Agent (Microsoft 365 Copilot), embedded directly on this page — paste the brief above into it and it will search, verify, and generate the shortlist Excel itself, handing you back a downloadable file right in the chat. This tool never contacts LinkedIn itself, and never invents a candidate or a profile URL — it only prepares the search brief handed to the embedded sourcing agent.
