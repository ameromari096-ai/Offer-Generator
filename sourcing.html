Step 1 · Generate the sourcing brief

This site has no server and no LinkedIn or AI API access, so it can't run a live LinkedIn search itself (see the README). Instead it builds a complete, ready-to-run brief — with the full sourcing ruleset and every filter above baked in — ready to copy and paste into the PureHealth Sourcing Agent chat below.

Step 2 · Open the Sourcing Agent

Copy the brief above, then open the live PureHealth Sourcing Agent (Microsoft 365 Copilot) and paste it in. Microsoft blocks its sign-in page from loading inside an embedded frame, so it opens in its own tab — the agent will search, verify, and generate the shortlist Excel itself, handing you back a downloadable file right in the chat.
